# Кафе «Белка» — лендинг

Учебный проект для портфолио: одностраничный сайт вымышленного кафе в Москве.
Вёрстка с нуля, без фреймворков — только HTML, CSS и немного ванильного JavaScript.

## Что внутри

- **Первый экран** с полноэкранной фотографией, слоганом и бегущей строкой.
- **Блок слоганов** — три коротких тезиса о характере заведения.
- **О кафе** — текст, фотография и блок с цифрами.
- **Атмосфера** — сетка фотографий разной высоты с подписями.
- **Меню** — три раздела (сэндвичи, десерты, напитки) с переключением вкладок;
  у каждой позиции состав, вес, калорийность, цена и метки вроде «хит» или «вег».
- **Контакты** — реквизиты заведения и карта OpenStreetMap с меткой.

## Технические решения

- Адаптивная вёрстка на CSS Grid и Flexbox, три контрольные точки: 1024, 820 и 520 px.
- Появление блоков при прокрутке через `IntersectionObserver`; анимация включается
  только при работающем JavaScript, плюс есть страховка, которая показывает
  содержимое, если наблюдатель не сработал.
- Учтён `prefers-reduced-motion`: при системной настройке анимации отключаются.
- Мобильная навигация с бургер-меню и корректными ARIA-атрибутами.
- Карта подключена без API-ключей — через встраиваемый фрейм OpenStreetMap.

## Структура

```
index.html        разметка страницы
css/styles.css    стили
js/main.js        меню, вкладки, появление блоков
favicon.svg       иконка сайта
```

## Как запустить

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python -m http.server 5599
```

Затем открыть http://localhost:5599.
